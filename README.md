## Selected Impact

### Enterprise Analytics Modernization
Led multiple workstreams in a $2.4M enterprise analytics transformation.
- Re-architected legacy data ingestion by replacing an on-prem R web crawler with Python-based API pipelines running concurrently on AWS Lambda and Step Functions
- Ingested raw data into S3 and Snowflake via Snowpipe, reducing processing time from **6 days to 4 hours (~97% improvement)**
- Designed scalable Snowflake data models and views supporting SQL exploration for **300+ non-technical users**
- Migrated dashboards to a cloud-native platform, contributing to **$900M in cost savings**
- Established reusable architectural patterns and documentation adopted across teams

### Cloud Cost Optimization & Architecture Strategy
Partnered with executive leadership to align analytics architecture with business goals.
- Migrated data science workloads off EC2 into Snowflake + AWS serverless
- Reduced infrastructure costs by **~20%** while improving performance and reliability
- Balanced scalability, cost, and maintainability for long-term platform growth

### ERP Reporting Migration (Oracle Fusion)
Technical lead for HCM and Finance reporting migration from PeopleSoft to Oracle Fusion.

- Led cross-functional teams under tight timelines while maintaining reporting continuity
